# AXL.DEV

Сайт-портфолио Александра Павленко для задания ГУАП. Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

[Сайт на GitHub Pages](https://paxls.github.io/My_portfolio/) · [QR-код](assets/qr-code.svg)

## Шаблон

За основу взята разметка [Start Bootstrap Freelancer](https://github.com/StartBootstrap/startbootstrap-freelancer/blob/master/src/pug/index.pug). Снимок исходного шаблона сохранён в `template/index.pug`, лицензия MIT — в `LICENSE`. В доработанной версии сохранена структура из навигации, первого экрана, портфолио, биографии, формы и подвала. Первый экран и карточки перевёрстаны, добавлены собственные CSS, SVG-иконка, мобильное меню и диалоги проектов. Текст и иллюстрации заменены.

## Проверка

Проверены ширины 320, 390 и 1440 пикселей. На мобильной ширине меню открывается, сворачивается после выбора раздела и меняет якорь. Диалог проекта закрывается клавишей Escape. Поле email показывает ошибку для адреса без `@` и убирает её после исправления. Форма передаёт заполненные поля в почтовое приложение как черновик.

## Размещение

GitHub Pages использует корневую папку ветки `main`. QR-код указывает на адрес этого репозитория в GitHub Pages.
